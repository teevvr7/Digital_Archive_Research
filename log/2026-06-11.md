## Status
Milestone D **COMPLETE** — all search features verified in browser.

## Bugs found and fixed during E2E

### 1. Fuzzy filename threshold too strict
**Symptom:** "invioce" → 0 results even though `word_similarity = 0.375` in raw SQL.  
**Root cause:** Server was running stale code (uvicorn `--reload` reloaded mid-edit sequence; child worker process 21904 survived parent kill 14884, kept serving old code).  
**Code fix:** Switched from `%>` operator (subject to session GUC default of 0.6) to explicit `func.word_similarity(q.lower(), func.lower(filename)) >= 0.2`. Now case-insensitive and threshold is embedded in the query, not the session.

### 2. Partial word results had no snippet highlighting
**Symptom:** Searching "inv" returned invoice docs but snippet had no `<mark>` tags.  
**Root cause:** `ts_headline` was receiving `websearch_to_tsquery('english', 'inv')` — "inv" is not a valid English lexeme so ts_headline found nothing to mark.  
**Code fix:** Added `build_headline_tsquery(q)` that builds a prefix tsquery (`to_tsquery('english', 'inv:*')`). `snippet_expr` now uses this for highlighting while `content_match` and `rank_expr` still use the exact tsquery for matching/ranking.

### 3. Stale uvicorn process
**Symptom:** `taskkill /PID <reloader-pid>` reported success but port 8001 stayed live.  
**Root cause:** Uvicorn `--reload` spawns a reloader parent and a server child. Killing the parent doesn't kill the child (it re-parents). Must kill the child PID directly (visible in startup log: "Started server process [XXXX]").  
**Fix going forward:** Run without `--reload` in dev, or use `--reload` but track the child PID.
