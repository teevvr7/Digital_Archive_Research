## Critical Finding (deferred to Milestone E)

**The FastAPI backend connects to Supabase as the `postgres` role, which has `bypassrls = true`.** This means RLS policies are not enforced at the database level for any production API request. The service layer scopes queries correctly per tenant (no cross-tenant data leaks in practice), but there is no DB-level safety net.

**Fix plan (Milestone E):** Create a custom Postgres role without bypassrls, grant it table access, and change `DATABASE_URL` to connect as that role instead of `postgres`.
