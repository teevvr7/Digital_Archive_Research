3. Technical Issues / Support Tickets Handled

Issue Number: 1
User / Project: Template Query / 422 Unprocessable Entity
Issue Description: Accessing templates returned a parameter parsing validation error.
Root Cause: FastAPI matched the URL "/templates" against the wildcard pattern "/{document_type_id}" and failed to parse it as a UUID.
Resolution Provided: Moved static route definitions above parameter-based wildcard routes in the router.

Issue Number: 2
User / Project: AI Server / Missing Modality Support
Issue Description: The remote server was only processing text OCR and did not send image data to Qwen-VL.
Resolution Provided: Refactored the remote endpoint to process base64 image strings and accept modality toggles.
