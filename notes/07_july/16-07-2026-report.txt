3. Technical Issues / Support Tickets Handled

Issue Number: 1
Issue Description: Development notebook cannot identify the local Python environment.
Root Cause: The project virtual environment folder was nested deep in the directory and ignored by the editor.
Resolution Provided: Registered the correct Python environment path within the editor's workspace configuration settings.

Issue Number: 2
Issue Description: Database connection check fails with a vague error code.
Root Cause: The test script expected query outputs as simple lists, but the database returned them as name-mapped columns, causing a index mismatch.
Resolution Provided: Adjusted the test check to read database outputs dynamically.

Issue Number: 3
Issue Description: Command execution crashes when printing output containing checkmark icons.
Root Cause: Default Windows command consoles use old character sets that do not support special emoji symbols.
Resolution Provided: Replaced the checkmark emoji in the print statements with simple ASCII text.
