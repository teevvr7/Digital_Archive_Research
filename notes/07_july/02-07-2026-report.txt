Issue Number: 1
Issue Description: Active debug logs (raw OCR output, full prompt, etc.) on the AI server showed empty titles with no body.
Root Cause: Variables were refactored into concurrent thread task scopes and were missing or empty in the top-level route handler where logs were being printed.
Resolution Provided: Shifted logging logic inside the parallel thread executor function to print actual output strings as they execute.
