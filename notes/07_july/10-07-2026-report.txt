3. Technical Issues / Support Tickets Handled

Issue Number: 1
Issue Description: Spreadsheet column picker does not display columns if no documents match the filter in the database.
Root Cause: discover_fields only queried existing documents' extracted_data keys.
Resolution Provided: Updated the discover_fields resolver to first load keys from DocumentTemplate.field_mappings or DocumentType.json_schema, unioning them with the database keys.

Issue Number: 2
Issue Description: Filter parameters for template, date range, and document type not working.
Root Cause: Request schemas in router.py inherited from BaseModel instead of CamelModel, causing camelCase request parameters to be ignored.
Resolution Provided: Refactored the schemas to inherit from CamelModel and defined attributes in snake_case.

Issue Number: 3
Issue Description: Table preview showing "[object Object]" and CSV cells containing Python dictionary representations.
Root Cause: Flat string formatting of complex/nested properties on frontend and default Python dict/list string representation in csv.DictWriter.
Resolution Provided: Used JSON.stringify in formatCellValue on the frontend and json.dumps in DictWriter on the backend.
