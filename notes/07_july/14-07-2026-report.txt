3. Technical Issues / Support Tickets Handled

Issue Number: 1
Issue Description: High key variance in extraction schemas across document formats breaks hardcoded serializers.
Root Cause: Different invoices extract varying keys for identical properties (e.g. `vendor_name` vs `supplier` vs `vendor`).
Resolution Provided: Created a generic, recursive JSON-to-Markdown converter that formats nested lists, lists of objects, and scalars into readable text without relying on hardcoded field keys.

Issue Number: 2
Issue Description: Pure vector search fails on exact identification codes (e.g. searching for invoice number `INV-2026-0042`).
Root Cause: Vector similarity models prioritise semantic meanings and frequently fail at exact numeric/code matches.
Resolution Provided: Designed a hybrid search pipeline that merges `pgvector` results with Postgres Full-Text Search using Reciprocal Rank Fusion (RRF).

5. Challenges Faced & Solutions Applied

Challenge: Embedding cross-encoder models inside the Docker image significantly inflates container build sizes (~2GB) and burdens deployment.
Solution: Decoupled advanced modules (re-ranking, query rewriting, and baseline keyword engine comparisons) into offline Jupyter notebooks for testing, keeping the core Streamlit container lightweight and fast to launch.
