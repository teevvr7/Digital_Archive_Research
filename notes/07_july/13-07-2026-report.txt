3. Technical Issues / Support Tickets Handled

Issue Number: 1
Issue Description: Loading embedding models on demand creates massive latency spikes.
Root Cause: The proposed retrieval module instantiated `SentenceTransformer("all-MiniLM-L6-v2")` inside the API request/response loop, causing a 2-5 second process startup delay on every user question.
Resolution Provided: Outlined a singleton import pattern to pre-load the model once during application process startup, mimicking the PaddleOCR pattern.

Issue Number: 2
Issue Description: Naïve character-based sliding-window chunking slices database records arbitrarily.
Root Cause: Standard character-based recursive splitting (e.g. 500 characters, 100 character overlap) tears line-item tables in half and splits values from their metadata.
Resolution Provided: Suggested converting extracted JSON properties into structured key-value template strings before embedding so each document chunk is self-contained.
