3. Technical Issues / Support Tickets Handled

Issue Number: 1
User / Project: IDP Control Center / Extraction Queue
Issue Description: Custom system instructions, rules, and schemas saved in the UI are ignored during document extraction.
Root Cause: New document uploads do not have a layout fingerprint (`doc.template_id` is None), causing the background worker to bypass the tenant's promoted template and fall back directly to the global, static `DocumentType` schema.
Resolution Provided: Designed a prioritized template resolution flow to check for a tenant's promoted template if `doc.template_id` is None.

5. Challenges Faced & Solutions Applied

Challenge: PostgreSQL JSONB columns normalization automatically sorting keys alphabetically, which ruins the linear top-down prompting sequence required for optimal Qwen-VL extraction.
Solution: Developed a metadata string serialization strategy that dumps the ordered schema to a string and stores it as plain text in the JSONB payload, preserving the exact admin-designed order.

Challenge: Silent mock fallbacks masking connection and remote server failures in production/staging environments.
Solution: Implemented a configuration-controlled `allow_mock_fallback` flag (defaulting to False) that lets connection errors raise visible exceptions and mark documents as FAILED.
